## 4. Bulk Certificate Generation via Canva
1. Export participant list to CSV with column `Name`.
2. Open Canva -> Open official HackerRank Certificate Template.
3. Place text box for candidate name.
4. Open **Apps** sidebar -> Search & select **Bulk Create**.
5. Upload CSV file -> Right click name box -> Select **Connect Data** -> choose `Name`.
6. Click **Continue** -> **Generate Designs** -> Export as PDF / PNG.

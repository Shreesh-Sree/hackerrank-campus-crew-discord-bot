## 2. Project Overview & Architecture

`hrcc_bot` is a modular, high-throughput Python 3.11+ Discord assistant for the **HackerRank Campus Crew (HRCC)** ambassador program. It is grounded in the official Ambassador Handbook (`handbook.hackerrankcampuscrew.xyz`) and connects to a local **vLLM** inference server on `ai-server` (`10.1.53.27:8000` / `127.0.0.1:8000`).

### Core Architecture Components
- **Framework:** `discord.py` (v2.3+ async) + `httpx` (async vLLM client) + `pydantic` / `pydantic-settings` (v2+ validation).
- **Inference Engine:** vLLM running `neuralmagic/Meta-Llama-3.1-8B-Instruct-FP8` (OpenAI-compatible `/v1/chat/completions`).
- **Knowledge Base:** `knowledge_data.yaml` and reference docs in `references/` (`handbook.md`, `sops.md`, `templates.md`).
- **Deterministic Multi-Rubric Intent Pipeline:**
  1. **Noise & Chatter Gate (Rubric 1):** Classifies incoming channel messages. If casual banter or off-topic, outputs `NO_REPLY` and silently drops (0 API calls, cancels typing immediately).
  2. **Direct Mentions & DMs:** Always processed through the specialized context engine.
  3. **Platform Separation (Rubric 3):** Strictly differentiates:
     - **HRW (`hackerrank.com/work/login`):** Enterprise platform for official monthly campus tests. **The `Chakra` tab is strictly internal; ambassadors must never access it.**
     - **HRC (`hackerrank.com`):** Standard community platform used as a fallback if HRW access is pending or for massive concurrent tests.
     - **SkillUp (`hackerrank.com/skillup`):** Self-paced student learning. Never use it to host campus events.
  4. **Rewards Calculation (Rubric 4):**
     - `< 300 participants`: 1-Year HackerRank Infinity Plan, Mock Interview credits, 6-Month AI Tools access for winners.
     - `≥ 300 participants`: All the above plus official HackerRank merchandise.
     - All participants submitting code/answers receive official participation certificates.
  5. **Certificate Delivery (Rubric 5):** Validates CSV schemas for Canva bulk certificates, requires code/answer submission proof.
  6. **Escalation Router (Rubric 6):**
     - **Sanskruti (Program Manager):** Rewards activation, welcome kits, onboarding, speaker/judge requests.
     - **Sreesanth (Technical Lead):** Platform bugs, HRW access, SkillUp issues.
     - **Nitish (Design Lead):** Brand assets, certificate templates, visual guidelines.
  7. **Safety & Formatting (Rubric 7):** Prompt injection filtering, token redaction, intelligent 2,000-character chunking preserving code blocks.

## 3. Code & Engineering Standards

- **Python Version:** Python 3.11+.
- **Typing:** Strict type annotations on all functions, methods, and classes (`mypy` compatible).
- **Asynchronous I/O:** Never perform blocking operations in the Discord event loop. Use `asyncio`, `httpx.AsyncClient`, and non-blocking file I/O.
- **Pydantic Configuration:** Load all settings from `.env` via `pydantic-settings` (`BaseSettings`).
- **No Thread Spawning:** Responses must be sent as direct channel replies (`message.reply(..., mention_author=False)`), not by automatically spawning Discord threads.
- **Error Handling:** Graceful fallbacks with exponential backoff on vLLM timeouts; log errors with structured logging.

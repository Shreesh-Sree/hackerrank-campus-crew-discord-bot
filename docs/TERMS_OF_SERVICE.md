## 2. Description of Service
The Bot is an automated assistant engineered specifically for student ambassadors, faculty advisors, and participants of the **HackerRank Campus Crew** ecosystem. Core features include:
- Generating event standard operating procedure (SOP) checklists for coding contests, hackathons, and workshops.
- Calculating reward eligibility based on active participant counts (`< 300` vs `≥ 300`).
- Validating contest result files (`.csv` / `.xlsx`) and generating normalized Canva Bulk Create files for certificate generation.
- Dispatching escalation tickets to program leadership (**Sanskruti**, **Sreesanth**, and **Nitish**).
- Automated event timeline reminders and promotional copy generation.
